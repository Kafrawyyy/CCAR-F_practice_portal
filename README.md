# CCAF Scenario Drills

Practice questions for the **Claude Certified Architect – Foundations (CCAR-F)** exam.

- **120 questions:** 20 per exam scenario, 10 easy and 10 hard
- **Practice mode:** pick a scenario and see right/wrong plus the explanation after each question
- **Mock exam:** 4 random scenarios × 15 questions = 60 items, with a 120-minute timer, like the real exam
- **Results:** score by scenario, domain and difficulty, with a review of missed questions

Everything is in one file, `index.html`. It has no build step and no server code. Progress is saved in each visitor's own browser.

**Live site:** https://kafrawyyy.github.io/CCAR-F_practice_portal/

## The six scenarios

1. Customer Support Resolution Agent
2. Code Generation with Claude Code
3. Multi-Agent Research System
4. Developer Productivity with Claude
5. Claude Code for Continuous Integration
6. Structured Data Extraction

## Run it locally

Open `index.html` in any browser.
